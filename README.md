# 🛍️ Shopping Behavior Data Analysis

## Project Overview

This project was completed as part of my internship at **Eagle-Hitech Softclou Private Limited, Chennai**. It focuses on analyzing shopping behavior data to identify customer purchasing patterns, explore spending trends, and derive meaningful insights using Python and data analytics techniques.

## Objectives

- Analyze customer shopping behavior and purchasing trends.
- Explore customer demographics and product category preferences.
- Examine purchase amounts, seasonal trends, and payment methods.
- Perform exploratory data analysis and statistical analysis.
- Apply data visualization techniques to communicate findings.
- Explore machine learning approaches for customer and purchasing behavior analysis.

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy
- Scikit-learn

## Project Files

- `shopping_behavior_analysis.ipynb` — Jupyter Notebook containing the data analysis and modeling workflow.
- `shopping_behavior_updated.xls` — Dataset used for the analysis.

## Work Performed

- Explored and analyzed shopping behavior data.
- Examined customer demographics, purchase amounts, product categories, and payment preferences.
- Created visualizations to identify patterns and trends.
- Conducted statistical analysis to explore differences in customer spending.
- Explored machine learning techniques for predictive analysis and customer segmentation.

## Key Learning Outcomes

- Gained practical experience in data cleaning and exploratory data analysis.
- Improved skills in Python-based data manipulation and visualization.
- Learned to investigate data patterns using statistical methods.
- Developed an understanding of machine learning workflows for business data.

## How to Run

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Ensure the dataset path and file format match the notebook code.
5. Run the notebook cells in sequence.
